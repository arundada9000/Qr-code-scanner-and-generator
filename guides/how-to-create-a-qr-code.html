How to Create a QR Code

Creating a QR code takes about twenty seconds once you know the steps — and it's completely free with SajiloQR. This guide walks you through creating codes for the three most common things people need: a website link, plain text, and a Wi-Fi network. Then it covers the few details that separate a code that scans instantly from one that fails in the real world.

Before you start: know what you're encoding

A QR code is just a way of storing text. The "text" can be a web address, a sentence, or a specially formatted string that tells a phone "connect to this Wi-Fi network". Because the code stores the information directly in its pattern, you need to decide the content first — you can't change it later without generating a new code.

Step 1: Open the generator and pick a type

On the SajiloQR home page, the Create QR card has a Type dropdown with three options:

  • URL / Website — for any web link.
  • Plain Text — for text that doesn't need to open anything.
  • Wi-Fi Network — for a code that connects a phone to a network.

Step 2: Enter your content

For a URL: paste the full address, including https:// — for example https://easyqrcreate.netlify.app/. Including the protocol matters: a phone needs to know the text is a web address to offer "open in browser".

For plain text: type whatever you want the scanner to show — a serial number, a note, a short instruction. The decoded result is displayed as text rather than opening anything.

For Wi-Fi: enter the network name (SSID) and password. SajiloQR builds the special Wi-Fi format for you, so you don't need to learn the syntax. One caveat worth repeating: the password is readable by anyone who scans the code, so only share it with people you trust.

Step 3: Watch it render

The code updates instantly as you type — there's no "Generate" button to press and no waiting. You'll see the familiar square grid appear in the card. If the field is empty, the code disappears and the download button hides, which is your visual cue that nothing is ready to save.

Step 4: Download as PNG

Once the code is on screen, click Download PNG. The tool saves a crisp, high-resolution image with a white quiet zone (the empty border) already included — that border is essential for scanning, so leaving it in is deliberate. The file downloads straight to your device, ready to drop into a document, poster, slide, or label.

Step 5: Test the code before you print or share

This is the step most people skip, and it's the one that saves the most embarrassment. Before printing a hundred flyers or sticking a code on a poster:

  • Scan it yourself with your phone's camera or SajiloQR's scanner.
  • Check the destination — make sure the link opens the right page, not a typo'd version of it.
  • Test from the distance someone will actually scan from. If it won't scan from two metres away, it's too small or too low-contrast.

Tips for codes that always scan

  • Keep it dark on light. Black modules on a white background scan best. Avoid light-on-dark codes, which many scanners struggle with.
  • Give it space. Keep the area around the code clear of text, logos, and busy patterns. The quiet zone should be at least four modules wide.
  • Don't go too small. For printed material, aim for at least 2 cm (about 0.8 in) wide.
  • Keep it short. A short URL makes a sparse, easy-to-scan code. If your link is long, consider a redirect service to shorten it first — just make sure it's a service you control, so the link doesn't die later.

Static vs dynamic codes: the one decision to understand

Codes you create with SajiloQR are static: the data is baked into the pattern forever, and the code never expires. The alternative is a "dynamic" code sold by paid services, which points to a redirect address you control. Dynamic codes let you change the destination after printing, but they stop working if the service shuts down or the subscription lapses. For almost everything, a static code is the right choice — it's free, permanent, and needs no third party to keep working.

Common mistakes and how to avoid them

  • Missing https:// — without it, some phones show the text instead of opening the page.
  • Forgetting the password type — if your Wi-Fi uses WPA2 or WPA3, the format SajiloQR builds works with modern phones. Older open networks work too, but the QR format assumes WPA/WPA2 by default.
  • Re-using an old QR code — if your URL changes, you must generate a new code. The old pattern still points to the old destination.
